# Ji bo Yaramin — Birthday Surprise

This is a free static website for GitHub Pages.

## Files
- `index.html` — page content in Kurmanji Kurdish
- `style.css` — romantic design, animated background and falling rose petals
- `script.js` — letter, interactions, cake, game, music controls

## Add your photos
Upload your photos into the `photos` folder with these exact names:
- `photo-1.jpeg`
- `photo-2.jpeg`
- `photo-3.jpeg`

If your images are `.jpg`, either rename the files to `.jpeg` or update the three image paths in `index.html`.

## Add music
Put your MP3 file in `assets` and name it `song.mp3`.
Music starts after the visitor taps the music button (mobile browsers block autoplay).

## Publish with GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
Your project URL will be `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

The site is public if the repository is public. Only upload photos you are comfortable sharing with anyone who has the link.
